## Интерактивные страницы

Самодостаточные HTML — открываются двойным кликом, ничего устанавливать не нужно.
Все числа в них получены прогоном на открытом датасете, не вписаны руками.

| Файл | О чём |
|---|---|
| [kak-schitaet-audit.html](kak-schitaet-audit.html) | Как работает движок: правило «не чинить данные молча», проверка данных с переключателями, живой тест Бенфорда по банкам, семь детекторов с формулами и уликами, матрица срабатываний, путь загруженного файла, карта кода. |
| [forma-skachka.html](forma-skachka.html) | Ветка `test`: три метрики формы скачка, PCA, голосование. Есть лаборатория — двигаешь статьи баланса ползунками и смотришь, как метрики переключают вердикт. |
| [skhema-bd.html](skhema-bd.html) | ER-схема `regtech.db`: четыре таблицы, две оси времени и то, чего в схеме нет. |

Страницы подстраиваются под светлую и тёмную тему системы.
